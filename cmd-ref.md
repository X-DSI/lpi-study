## 3.3 Scripting

| Item            | Exact form           | Note               |
| --------------- | -------------------- | ------------------ |
| shebang         | `#!/bin/bash`        | first line         |
| exit status     | `$?`                 | of last command    |
| positional arg  | `$1`, `$2`           | `$0` = script name |
| arg count       | `$#`                 |                    |
| make executable | `chmod +x script.sh` |                    |
